Our Solution

Prove age without revealing identity

CryptoAge combines anonymous biometric analysis, Zero-Knowledge Proofs, and short-lived cryptographic tokens to answer one question: "Old enough?"

🤖

Anonymous Face Analysis

Uses on-device ML to estimate age from a blurred/pixelated image. Raw pixels never leave your device. No face stored, no biometric record created.

🔐

Zero-Knowledge Proof (ZKP)

Mathematically proves "age ≥ 18" without revealing the actual age or any identity detail. The server learns nothing except the boolean answer.

⏱️

Short-Lived Tokens

A one-time cryptographic token (TTL: 60 seconds) is issued after verification. It expires automatically — nothing to steal later.

🗑️

Zero Retention Policy

No name, no DOB, no face — absolutely nothing personal is stored at any stage. Logs contain only pass/fail counts.

Under the hood

Core logic: estimate age on-device, generate ZKP, issue ephemeral token.

// 1. On-device age estimation (no data leaves device) async function estimateAgeOnDevice(videoElement) { const model = await loadAgeModel(); const canvas = document.createElement('canvas'); const ctx = canvas.getContext('2d'); ctx.filter = 'blur(12px)'; // anonymize immediately ctx.drawImage(videoElement, 0, 0); const estimatedAge = await model.predict(canvas); canvas.remove(); // discard — never stored return estimatedAge; } // 2. Generate Zero-Knowledge Proof (age ≥ 18, without revealing age) async function generateAgeProof(age) { const circuit = await loadCircuit('ageCheck.wasm'); const { proof, publicSignals } = await snarkjs.groth16.fullProve( { age, minAge: 18 }, circuit, 'ageCheck_final.zkey' ); // proof contains NO age value — only "age ≥ 18 is true" return { proof, publicSignals }; } // 3. Server: verify proof & issue ephemeral token app.post('/verify', async (req, res) => { const { proof, signals } = req.body; const valid = await snarkjs.groth16.verify(vKey, signals, proof); if (!valid) return res.status(403).json({ ok: false }); const token = jwt.sign({ ok: true }, SECRET, { expiresIn: '60s' }); res.json({ ok: true, token }); // No identity stored — ever. });
